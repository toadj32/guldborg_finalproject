Requirements:
- IDE
    - JetBrains Rider
    
To Run:
 Run the File, all textures should already be in Content.mgcb, and simulation should run off the start

Interactivity:
- To move components, click and drag them from the sidebar using the left mouse button
- To rotate a component, hold one and without releasing, right click to rotate it by 90 degrees.
- You can also use the left mouse button to click on other interactive buttons like the pause button, the settings, 
and the rules button. 
- If you are unable to drag a component, you either do not have enough money for it, which will reflect in it being 
grayed out, or you have already placed the component and cannot move it again. 
- You can mute the music in the settings tab or press the "m" key anytime during the game
- You can wait until you die to restart or press the "r" key to restart anytime midgame
- You can die or press the "b" key to return to the starting screen
- You can use the mouse to press the pause button or press the space bar to pause. 
    
Troubleshooting Notes
- Ensure that .config/dotnet-tools.json is unblocked --> go to prompt terminal if error occurs
    - Or unblock by right clicking on the file, going to properties, and checking the unblock box
- Ensure just the .sln file is opened if the run program button is grayed out
